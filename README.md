👋 About Me

Yo, I'm BoltZyy.

I'm mostly a vibe coder — I build things with code, AI, curiosity, and an unreasonable amount of trial and error.

I don't always code because I have to.

Sometimes I code because real life is busy, noisy, and exhausting, and coding is just a nice little escape route.

«Coding isn't always the destination. Sometimes it's the escape.»

I also genuinely enjoy building things together with AI.
I throw an idea at the AI, let it challenge my approach, break things, fix things, and somehow we eventually end up with something that works.

And yes...

Sometimes the code works.

Sometimes the code works after 47 increasingly questionable fixes.

That's the process. 😭

🚀 Featured Projects

🤖 "Vercel-dc" (https://github.com/BoltZyy/Vercel-dc)

My most feature-rich Discord bot project.

A serverless Discord bot running around the Vercel ecosystem, with things like AI interaction, economy systems, shop/trading mechanics, moderation, and asynchronous backend workflows.

Built with a healthy combination of actual engineering and:

«"Coba tanya AI dulu." 😭»

---

🧠 "Vercel-gateway" (https://github.com/BoltZyy/Vercel-gateway)

A serverless AI router/proxy designed to provide an OpenAI-compatible interface while routing requests across multiple AI providers.

Basically:

Your App
   ↓
Vercel Gateway
   ↓
AI Provider
   ↓
Response

Because apparently calling one AI API directly wasn't complicated enough.
