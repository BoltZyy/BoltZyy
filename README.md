👋 About Me

Yo, I'm BoltZyy.

I'm a vibe coder who likes turning random ideas into actual projects — usually with a suspicious amount of help from AI.

IRL, I'm pretty busy. So I don't always have the time (or energy) to sit down and become a perfectly disciplined developer.

Instead, I found something I genuinely enjoy:

coding with AI.

For me, coding isn't always about building something useful, getting a job done, or following some perfect development roadmap.

Sometimes, I just want to escape for a while.

I can open my editor, throw some ridiculous idea at an AI, start building, break everything, fix it, and somehow end up with an actual working project.

And honestly?

«"I don't always code because I have to.
Sometimes I code because I want somewhere else to be for a while."»

🚀 Featured Projects

🤖 "Vercel-dc" (https://github.com/BoltZyy/Vercel-dc)

My main Discord bot project.

A serverless Discord bot running on Vercel, combining AI features with a larger backend system including economy, shop, bank, moderation, trading-style mechanics, scheduled jobs, Redis, and more.

Stack: Vercel • Discord • Upstash Redis • QStash • AI

---

⚡ "Vercel-gateway" (https://github.com/BoltZyy/Vercel-gateway)

A serverless AI router/proxy built around an OpenAI-compatible API interface.

It connects multiple AI providers with fallback logic, making it possible to route requests between different providers instead of relying on just one.

Stack: Vercel • JavaScript • AI APIs • Fallback Routing

---

🤖 "Discord-bot-vercel" (https://github.com/BoltZyy/Discord-bot-vercel)

One of my earlier serverless Discord bot projects.

Built around Discord HTTP Interactions, Vercel Serverless Functions, Redis, and multiple AI providers.

Stack: Discord • Vercel • Upstash Redis • Gemini • Groq • OpenRouter
